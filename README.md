# Skill Builder

แบบฟอร์มสร้าง skill (ไฟล์ `SKILL.md`) สำหรับนำเข้า AI agent — กรอกทีละหมวด ระบบเขียนไฟล์ให้สดๆ พร้อมตรวจความพร้อมก่อนนำเข้า

**เปิดใช้งาน** (เลือกลิงก์ไหนก็ได้ เนื้อหาเหมือนกัน):

- Netlify: https://knot-skill-builder.netlify.app
- GitHub Pages: https://not1147.github.io/knot-skill-builder/

## ใช้ทำอะไร

- กรอกข้อมูล 10 หมวด: ตัวตนของ skill, ขอบเขต, ข้อมูลนำเข้า, ขั้นตอน, ผลลัพธ์, กฎ, ตัวอย่าง, กรณีพิเศษ, ความรู้เฉพาะทาง, การตรวจงาน
- พรีวิว `SKILL.md`, `evals.md` และโครงสร้างโฟลเดอร์แบบสด
- ดาวน์โหลด `.zip` ที่พร้อมอัปโหลดเข้า Claude (Settings › Capabilities › Skills) หรือวางในโฟลเดอร์ skills ของ agent อื่น
- บันทึกร่างอัตโนมัติในเบราว์เซอร์ และบันทึก/เปิดร่างเป็นไฟล์ `.json`

## ใช้แบบออฟไลน์

ดาวน์โหลด `index.html` แล้วดับเบิลคลิกเปิดใน Chrome หรือ Edge ได้เลย ไม่ต้องติดตั้งอะไร ทุกอย่างอยู่ในไฟล์เดียว

## ความเป็นส่วนตัว

ข้อมูลที่กรอกเก็บอยู่ในเบราว์เซอร์ของผู้ใช้แต่ละคนเท่านั้น ไม่มีการส่งขึ้นเซิร์ฟเวอร์
