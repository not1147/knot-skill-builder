แบบฟอร์มสร้าง skill ให้ AI agent

0%

    ชี้หรือแตะไอคอน ข้างชื่อช่องเพื่อดูว่าต้องกรอกอะไร · ตัวเอียงสีจาง คือข้อมูลตัวอย่าง พิมพ์ทับได้เลย

    ตัวตนของ skill

    agent ใช้ชื่อและคำอธิบายนี้ตัดสินใจว่าจะหยิบ skill นี้มาใช้หรือไม่ จึงสำคัญที่สุดในฟอร์ม

    เป้าหมายและขอบเขต

    บอกให้ชัดว่างานจบตรงไหน agent จะไม่ทำเกินหรือทำขาด

    ข้อมูลนำเข้า

    ต้องได้อะไรจากผู้ใช้ก่อนเริ่มงาน และถ้าขาดให้ทำอย่างไร

    ขั้นตอนการทำงาน

    เรียงลำดับ บอกทั้งทำอะไร และต้องตรวจอะไรก่อนไปขั้นต่อไป

    รูปแบบผลลัพธ์

    ยิ่งระบุละเอียด ผลยิ่งออกมาเหมือนกันทุกครั้ง

    กฎและข้อห้าม

    สิ่งที่ต้องทำและห้ามทำแบบเด็ดขาด ใส่เหตุผลกำกับจะช่วยให้ agent ตัดสินใจถูกในกรณีที่ไม่ได้เขียนไว้

    ตัวอย่าง

    ตัวอย่างจริง 1–3 ชุด สอน agent ได้ดีกว่าคำอธิบายยาวๆ

    กรณีพิเศษและข้อผิดพลาด

    จุดที่ agent มักพลาด เช่น ข้อมูลว่าง ค่าแปลก ไฟล์ผิดรูปแบบ

    ความรู้เฉพาะทาง

    คำศัพท์และนิยามขององค์กรที่ agent ไม่มีทางรู้เอง และไฟล์ประกอบในโฟลเดอร์ skill

    ตรวจงานก่อนส่ง

    นิยามว่างานเสร็จคืออะไร ให้ agent เช็กตัวเองก่อนตอบ และชุดคำสั่งไว้ทดสอบ skill
